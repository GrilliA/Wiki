# Navigation Bar

- This navigation bar shall be fixed at the top of the viewport.
- The Navigation bar shall contain:

  - The logo at left corner (when clicked, it shall redirect to the homepage)

  - The search bar on the right (if no user is logged in, make it an input)

  - The user icon at the right corner (if the user is logged in)
    When clicked, it shall open a dropdown menu with:

    - Profile
    - Settings
    - Reserved Area
    - Logout

  - A generic hamburger menu, which contains (same for both mobile and desktop):

    - Home
    - Our Mission
    - Contact us
    - Work with us
    - Login (if no user is logged in)
    - Sign Up (if no user is logged in)

  - There shall be a note under the navigation bar (it can be closed),
    that say: "Are you part of the team? Login here" (with a link to the login page)
