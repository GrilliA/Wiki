# Profile

- The following profile info shall be displayed:

  - Profile Picture
  - Username
  - Bio

- There shall be an "Edit Profile" button that redirects to the Edit Profile page:

  - Profile Picture (file upload) - Optional
  - Username (text input) - Required, must be unique
  - First Name (text input) - Required (it must be specified that this information won't be public)
  - Last Name (text input) - Required (it must be specified that this information won't be public)
  - Bio (textarea with quill editor) - Optional, max 300 characters

- There shall be a list of contributions made by the user (if any)
  - When clicking on a contribution, it shall redirect to the wiki detail page,

## Questions

- Can anyone view your contributions?
  yes, everything is transparent and viewable to anyone
- Does the diff page, has to be divided into two parts?
  yes, one for the original text and one for the modified text,
  but the priority is to show the changes made in a clear way
