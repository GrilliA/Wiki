# Forgotten Password Email

- There shall be an email template for the forgotten password email
- The email shall contain a link to reset the password, for example: `https://yourdomain.com/reset-password?token=someUniqueToken`

- The message shall be something like:

  ```
  Subject: Password Reset Request

  Hi [User's Name],

  We received a request to reset your password. Click the link below to set a new password:

  [Reset Password Link]

  If you did not request a password reset, please ignore this email.

  Best regards,
  Your Company Team
  ```
